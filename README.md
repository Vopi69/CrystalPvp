# Crystal Practice

Statická webová aplikace pro GitHub Pages.

## Spuštění
Otevři `index.html` v prohlížeči nebo nahraj všechny tři soubory (`index.html`, `style.css`, `script.js`) do kořene GitHub Pages repozitáře.

## Funkce
- Anchor Practice a Crystal Speed s 10sekundovým měřením
- nastavitelné klávesové bindy
- světlý/tmavý režim a 4 jazyky
- lokální statistiky a leaderboard v `localStorage`
- obrázky Minecraft itemů načítané z veřejného repozitáře assetů

Poznámka: jde o simulaci v prohlížeči, ne o přímé ovládání Minecraft klienta. Výsledky a žebříček jsou lokální pro daný prohlížeč.
